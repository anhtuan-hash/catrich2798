# Daily Teacher Assignment & Attendance History Delete Design

## Scope

Extend the existing admin-only extra-class attendance module. The change is independent from Homeroom/GVCN.

## Teacher assignment model

- Remove the attendance module's dependency on teacher account lists for day-to-day assignment.
- A teacher is entered as free text by an Admin for a specific extra class and teaching date.
- Exactly one teacher name is stored for each `(class_id, teaching_date)` pair.
- The teaching date is a Vietnam-local calendar date (`Asia/Ho_Chi_Minh`).
- Teacher assignments persist in Supabase and are shared across browsers/devices.
- The UI defaults the assignment date to today and lets Admin choose another date to prefill/edit a future or past assignment.
- Saving the same class/date again updates the teacher name instead of creating a duplicate.
- The existing class-level `teacher_id`, `teacher_name`, and `teacher_email` columns remain for backward compatibility but are no longer authoritative for attendance.

## Attendance confirmation

- Quick Attendance displays the teacher name saved for the selected class for today's Vietnam-local date.
- Admin may edit/save today's teacher name directly before attendance.
- Attendance confirmation is blocked until a non-empty teacher name is saved for today.
- The server-side confirmation RPC reads the saved daily teacher assignment for today's Vietnam-local date.
- The session stores a snapshot of `teaching_date` and `teacher_name`; later edits to the daily assignment do not rewrite historical sessions.
- `teacher_id` remains `NULL` and `teacher_email` remains empty for newly confirmed sessions under this model.
- Check-in time continues to be generated by the database server at confirmation time.

## Import and class management

- Excel import no longer requires or resolves a teacher account.
- Teacher-related columns in old templates may be present but are ignored for class identity and membership import.
- Class identity for import is `class_type + class_name + subject`.
- Creating a class manually does not require selecting a teacher account.

## Delete attendance history

- Admin can delete a previously confirmed attendance session from the History view.
- The UI must ask for confirmation before deletion and clearly show class name and recorded time.
- Deletion is performed only through a security-definer RPC.
- The RPC verifies Admin permission and deletes the selected session; student attendance records are removed atomically via the existing `ON DELETE CASCADE` relationship.
- After successful deletion, the History view refreshes and the deleted session is no longer shown.
- No direct client DELETE policy is added for attendance session/record tables.

## Database changes

Create `public.bes_extra_class_daily_teachers` with:

- `id uuid primary key default gen_random_uuid()`
- `class_id uuid not null references bes_extra_classes(id) on delete cascade`
- `teaching_date date not null`
- `teacher_name text not null`
- `created_by uuid not null references profiles(id)`
- `updated_by uuid not null references profiles(id)`
- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`
- unique constraint on `(class_id, teaching_date)`

Enable RLS. Admins may select/insert/update/delete daily teacher assignments. Anonymous access remains denied.

Add `teaching_date date` to `bes_extra_attendance_sessions`, backfilled from `checked_at AT TIME ZONE 'Asia/Ho_Chi_Minh'` for old rows and then made non-null.

Update `bes_confirm_extra_class_attendance` to require a saved daily teacher assignment for the current Vietnam-local date and snapshot its name/date into the session.

Add `bes_delete_extra_attendance_session(p_session_id uuid)` as a security-definer Admin-only RPC returning boolean.

## UI changes

### Quản lý lớp

Replace the teacher-account `<select>` with a compact daily assignment editor:

- date input
- text input labelled `Giáo viên đứng lớp`
- `Lưu giáo viên` button
- helper text stating `Mỗi lớp chỉ có 1 giáo viên cho mỗi ngày`

### Điểm danh nhanh

Show today's teacher above the roster. If missing, show the same text input + save action and disable `Xác nhận điểm danh` until it is saved.

### Lịch sử

Each history session shows `teaching_date`, teacher snapshot, check-in time, counts, and a red `Xóa điểm danh` action. Confirmation is required before invoking the delete RPC.

## Error handling

- Empty teacher names cannot be saved.
- Attendance RPC rejects confirmation when today's daily teacher assignment is missing.
- Deleting an unknown session returns a not-found error.
- RLS/RPC permission errors remain visible to Admin as actionable Vietnamese error messages.

- SQL contract verifies the daily teacher table, unique class/date constraint, `teaching_date` session snapshot, Admin-only delete RPC, and no direct DELETE policy on history tables.
